BYOW

Idea: This project is a Java-based game that dynamically generates a randomized world each time it runs. Players can navigate the environment using directional controls (up, down, left, right) while interacting with elements such as collectible coins to enhance gameplay. The game combines procedural generation with player interaction, making each playthrough unique and engaging..

F1 optimizing

Idea: Using Python for data processing and AMPL for mathematical modeling, the goal is to minimize travel time, costs, and other factors, ensuring that teams can efficiently manage their trips between race locations. This involves applying optimization techniques to plan the best routes, schedule, and travel arrangements, reducing overall resource usage while meeting the constraints of the racing season.
